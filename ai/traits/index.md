# 형질 데이터

AI가 관찰하고 기록할 수 있는 한국춘란의 형질을 구조화하기 위한 영역입니다.

## 1. 기본 원칙

현재 품종 데이터는 `cultivar_class`, `classification`, `traits`를 구분하여 관리합니다.

- `cultivar_class`: 사람이 도감에서 보는 품종의 대표 분류입니다.
- `classification`: 품종을 설명하는 주요 형질 축입니다.
- `traits`: 주요 형질 축을 더 자세히 기록하는 세부 관찰 정보입니다.
- `ai`: AI용 보조 라벨과 메모를 관리하며, canonical 분류와 형질을 중복 저장하지 않습니다.

대표 분류와 세부 형질은 하나로 합치지 않습니다. 세부 형질은 AI 데이터셋에서 독립적인 축으로 보존합니다.

## 2. 현재 확인된 형질 축

현재 저장소의 분류 표준에서 확인된 세부 형질 축은 다음과 같습니다.

### 엽예

- 잎의 형태: `leaf_form`
- 무늬: `pattern`
- 잎끝: `leaf_tip`
- 무늬 위치: `pattern_position`
- 무늬 발현: `pattern_timing`

현재 확인된 값은 `_data/categories.yml`에 정의된 값을 기준으로 합니다. 새로운 값은 실제 자료와 용어를 확인한 뒤 추가합니다.

### 화예

현재 품종 데이터에는 `traits.flower`가 존재하며, 꽃의 형태·색·기타 관찰 내용을 기록할 수 있는 구조가 마련되어 있습니다.

화예의 세부 분류와 값은 검증되지 않은 용어를 임의로 확장하지 않고, 관련 지식 자료와 품종 자료를 확인하면서 단계적으로 정리합니다.

## 3. 세부 관찰 정보

현재 `traits.leaf`에는 다음과 같은 관찰 필드가 사용되고 있습니다.

- `length`: 잎 길이
- `width`: 잎 폭
- `thickness`: 잎 두께
- `form`: 잎의 형태와 자세에 관한 관찰
- `tip`: 잎끝에 관한 관찰
- `texture`: 잎의 표면·질감에 관한 관찰
- `base_color`: 기본 잎색
- `variegation_color`: 무늬 색
- `notes`: 기타 관찰 기록

`traits.flower`에는 현재 `type`, `color`, `notes`가 사용되고 있습니다.

이 필드들은 현재 저장소에서 실제 사용 중인 구조이며, 앞으로의 확장에서도 기존 데이터를 깨뜨리지 않는 것을 우선합니다.

## 4. AI 관찰과 사람의 검증

형질 데이터는 AI의 관찰 결과와 사람이 확정해야 하는 정보를 구분하여 사용합니다.

### AI가 관찰하거나 후보를 만들 수 있는 정보

- 이미지에서 보이는 잎의 형태적 특징
- 무늬의 위치와 시각적 특징
- 잎끝의 형태적 특징
- 색과 질감에 관한 시각적 특징
- 사진에서 추출한 문자와 품종명 후보

### 사람이 검증해야 하는 정보

- 품종명
- 전시 카드의 OCR 결과
- 공식적인 분류와 품종 연결
- 용어의 적용 여부
- 최종 학습 데이터 채택 여부

AI의 관찰 결과를 곧바로 공식 품종 정보로 저장하지 않습니다.

## 5. 이미지 데이터셋과의 연결

형질 데이터는 향후 이미지 데이터셋과 연결됩니다.

기본 흐름은 다음과 같습니다.

```text
원본 이미지
    ↓
전시 구역 / 카드 / 사진 정보
    ↓
이미지에서 관찰되는 형질
    ↓
품종 후보 및 OCR 후보
    ↓
사람의 검증
    ↓
검증된 형질·품종 연결
    ↓
학습 데이터
```

이미지는 현재 이 영역에 직접 추가하지 않습니다. 이미지 데이터셋의 출처와 검증 구조를 먼저 확립한 뒤 연결합니다.

## 6. 확장 원칙

앞으로 형질을 추가할 때는 다음 순서를 따릅니다.

1. 실제 춘란 자료에서 용어와 관찰 기준을 확인합니다.
2. 기존 `classification`과 `traits` 중 어느 영역에 속하는지 결정합니다.
3. 기존 필드와 중복되는 새로운 필드를 만들지 않습니다.
4. 필요한 경우에만 새로운 형질 축이나 관찰 필드를 추가합니다.
5. 실제 품종 자료에 적용해 구조가 자연스러운지 확인합니다.
6. 이미지 데이터셋과 연결할 때 사람의 검증 상태를 별도로 관리합니다.

현재 단계에서는 확인되지 않은 형질값이나 품종 연결을 임의로 추가하지 않습니다.
