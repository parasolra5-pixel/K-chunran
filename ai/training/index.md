# 학습 데이터

검증된 춘란 데이터와 이미지를 실제 AI 학습에 사용할 수 있는 형태로 정리하기 위한 영역입니다.

## 정리 원칙

학습 데이터는 원본 이미지와 형질 데이터, AI의 관찰·후보 생성·대조·검증·감정 결과, 공식 품종 연결 정보를 단계적으로 연결하여 구성합니다.

기본 흐름은 다음과 같습니다.

```text
이미지
 ↓
형질 관찰
 ↓
형질 조합
 ↓
품종 후보
 ↓
기존 품종 JSON 대조
 ↓
AI 검증
 ↓
AI 감정
 ↓
공식 품종 연결
```

## 학습 데이터에 포함되는 정보

### 1. 원본과 이미지 정보

이미지의 출처와 식별 정보를 보존하고, 이미지 데이터셋에서 관리되는 원본·전시·카드·사진의 연결 관계를 유지합니다.

### 2. 형질 관찰 데이터

이미지에서 AI가 관찰한 잎과 꽃의 형질을 학습에 사용할 수 있는 관찰 정보로 기록합니다.

관찰 결과와 기존 품종의 공식 정보는 구분하여 저장합니다.

### 3. 품종 후보와 대조 데이터

관찰된 형질을 조합하여 생성한 품종 후보와 기존 품종 JSON과의 비교 결과를 기록합니다.

후보 생성 과정과 대조 근거를 보존하여 AI의 판단 과정을 추적할 수 있도록 합니다.

### 4. AI 검증 및 AI 감정 데이터

AI가 후보와 기존 품종 정보를 비교하여 검증한 결과와 최종 AI 감정 결과를 별도로 기록합니다.

AI 검증 결과와 AI 감정 결과를 하나의 공식 품종 정보로 간주하지 않습니다.

### 5. 공식 품종 연결 데이터

AI 감정 결과를 바탕으로 연결된 공식 품종 정보를 별도로 기록합니다.

공식 품종 연결은 AI의 관찰·후보·검증·감정 결과와 구분하여 관리합니다.

### 6. 전문가 연결 정보

사용자가 추가 감정을 원하는 경우 전문가 연결이 이루어질 수 있습니다.

전문가 연결 결과는 기본 AI 학습 데이터 생성의 필수 단계가 아니라 선택적인 후속 정보로 관리합니다.

## 학습 데이터 검증 원칙

- 확인되지 않은 원본 자료를 그대로 학습 데이터로 확정하지 않습니다.
- 이미지 관찰 정보와 공식 품종 정보를 구분합니다.
- AI의 관찰, 후보 생성, 대조, 검증, 감정 결과를 단계별로 보존합니다.
- 공식 품종 연결 정보는 별도의 연결 결과로 기록합니다.
- 선택적 전문가 감정 결과가 있는 경우 AI 결과와 구분하여 기록합니다.
- 실제 학습 데이터에 포함되는 기준은 향후 검증 체계가 확정된 뒤 구체화합니다.

현재는 구조만 먼저 만들고 실제 학습 데이터는 추가하지 않습니다.
