# K-Chunran 메뉴 구조 확정안

작성일: 2026-09-17
상태: 확정

## 1. 목적

K-Chunran은 단순한 춘란 도감이 아니라, 앞으로 AI가 한국춘란의 분류·형질·품종·이미지를 서로 연결해서 이해할 수 있도록 만드는 지식 기반이다.

따라서 메뉴도 사람에게 보기 좋은 단순 분류보다 다음 세 층이 명확하게 연결되도록 구성한다.

1. 실제 품종을 보는 층
2. 춘란 용어와 형질을 이해하는 지식 사전 층
3. 지식과 실제 이미지·관찰 데이터를 연결하는 AI 데이터 층

## 3. 각 메뉴의 역할

### 품종 도감

실제 한국춘란의 품종을 기록하고 찾아보는 곳이다.

명명품 아래에서 엽예품·화예품을 나누고, 산반·서반·중투호·홍화·황화·소심·원판화 등 실제 현장에서 사용하는 분류명으로 품종을 찾아볼 수 있게 한다.

`천종`, `세보`, `보름달`, `단심` 등 실제 품종명은 이 영역에 속한다.

한 품종이 엽예 또는 화예 한쪽의 정보만 가지는 것으로 제한하지 않는다. 품종 페이지에서는 잎 형질과 꽃 형질을 함께 연결할 수 있어야 한다.

### 춘란 지식 사전

AI가 한국춘란을 이해하기 위한 공유 지식층이다.

예를 들어 `산반`, `서반`, `중투`, `복륜`, `입엽`, `중수엽`, `홍화`, `황화`, `소심`, `원판화` 등의 용어를 각각 설명하고, 관련 형질·유사 용어·실제 품종과 연결한다.

같은 용어의 설명을 각 품종 페이지에 반복해서 기록하지 않는다. 용어는 지식 사전에서 한 번 정의하고, 품종은 해당 용어와 연결한다.

`잎끝`은 별도 상위 메뉴로 두지 않는다. 잎끝은 무늬의 위치·방향·깊이와 같은 관찰에서 사용되는 위치 정보로 다루며, 필요한 세부 형질은 지식·형질 데이터에서 보존한다.

### AI 데이터

춘란 지식 사전의 개념을 실제 관찰·이미지 데이터와 연결하는 곳이다.

형질 데이터, 품종 연결, 이미지 데이터셋, 학습 데이터를 별도로 관리한다.

이미지는 현재 품종 JSON에 직접 넣지 않고 별도 이미지 데이터셋으로 구축한 뒤 품종 ID와 연결한다.

## 4. 핵심 구조 원칙

```text
춘란 지식 사전
   ↓
용어·형질의 의미
   ↓
품종 도감
   ↓
실제 품종과 형질 연결
   ↓
AI 데이터
   ↓
사진·관찰값·검증 데이터
   ↓
AI 분석
```

즉,

- `춘란 지식 사전`은 무엇을 의미하는지 설명한다.
- `품종 도감`은 어떤 품종이 그 형질을 가지는지 연결한다.
- `AI 데이터`는 그 형질이 실제 이미지에서 어떻게 관찰되는지 기록한다.

## 5. 용어 사용 원칙

`원자 형질`은 한국춘란 현장에서 사용하는 공식 분류 용어가 아니라 AI 데이터 설계를 위해 사용했던 내부 설계 표현이다.

따라서 사용자에게 보여주는 메뉴와 지식 사전에서는 실제 한국춘란 용어를 우선 사용하고, 필요한 경우 내부 데이터 구조에서 `세부 형질` 또는 `형질 요소`로 표현한다.

또한 실제 현장에서 확인되지 않은 복합 분류명을 임의로 만들어내지 않는다.

## 6. 확정 상태

이 문서의 메뉴 구조를 K-Chunran의 기본 정보 구조로 확정한다.

앞으로 메뉴를 실제 코드에 반영할 때는 이 구조를 기준으로 하며, 개별 페이지의 세부 분류명은 실제 한국춘란 자료를 확인한 뒤 추가한다.

메뉴 확정과 실제 페이지 구현은 별개의 단계로 취급한다.
